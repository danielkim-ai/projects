# Theory: Trustworthy Offline RL via Differential Privacy and Machine Unlearning

This note documents the mathematical contract behind the prototype pipeline:

```text
offline trajectories -> trajectory DP-SGD -> deletion request -> unlearning audit
```

## 1. Offline RL Setup and Privacy Tension

Let the offline dataset be a finite population of trajectories.

$$\mathcal{D}=\{\tau_i\}_{i=1}^{n},\quad \tau_i=(s_{i,t},a_{i,t},r_{i,t},s'_{i,t},d_{i,t})_{t=0}^{T_i-1}.$$

The data are generated by an unknown behavior policy $\mu$.

$$\tau\sim p_\mu(\tau)=\rho_0(s_0)\prod_{t=0}^{T-1}\mu(a_t\mid s_t)P(s_{t+1}\mid s_t,a_t).$$

The learner wants a target policy $\pi$ whose expected discounted return is

$$J(\pi)=\mathbb{E}_{\tau\sim p_\pi}\left[\sum_{t=0}^{T-1}\gamma^t r(s_t,a_t)\right].$$

Offline RL is statistically fragile because the occupancy measure of $\pi$ can differ from the logged behavior distribution.

$$d^\pi(s,a)\neq d^\mu(s,a).$$

When $Q_\theta(s,a)$ is queried outside the support of $d^\mu$, Bellman bootstrapping can amplify OOD overestimation. Privacy adds a second tension: the same trajectory often represents one user's correlated longitudinal record.

### Why Transition-Level Adjacency Is Insufficient

Transition-level adjacency treats two datasets as adjacent if they differ by a single transition.

$$\mathcal{D}\sim_{\text{trans}}\mathcal{D}'\Longleftrightarrow |\mathcal{D}\triangle\mathcal{D}'|=1.$$

This is too small a privacy unit for sequential data. If $g_{i,t}=\nabla_\theta\ell(\theta;s_{i,t},a_{i,t},r_{i,t},s'_{i,t})$, then transitions from one episode are not independent.

$$\text{Cov}(g_{i,t},g_{i,t+k})\neq 0.$$

The trajectory gradient is the correlated sum

$$G_i=\sum_{t=0}^{T_i-1}g_{i,t}.$$

Its second moment contains cross-transition covariance terms.

$$\mathbb{E}\|G_i\|_2^2=\sum_t\mathbb{E}\|g_{i,t}\|_2^2+2\sum_{t<u}\mathbb{E}\langle g_{i,t},g_{i,u}\rangle.$$

If the covariance terms are positive, transition-level clipping understates sensitivity. The relevant sensitivity is trajectory-level:

$$\Delta_{\text{traj}}=\max_{\tau,\tau'}\|\nabla\ell(\tau)-\nabla\ell(\tau')\|_2.$$

This is not generally approximated by a one-transition sensitivity:

$$\Delta_{\text{traj}}\not\approx\max_t\|g_t-g'_t\|_2.$$

Trajectory-level adjacency therefore defines neighboring datasets by adding or removing one full episode.

$$\mathcal{D}\sim_{\text{traj}}\mathcal{D}'\Longleftrightarrow \mathcal{D}'=\mathcal{D}\setminus\{\tau_k\}\ \text{or}\ \mathcal{D}'=\mathcal{D}\cup\{\tau_k\}.$$

This matches the deletion and privacy unit used by the framework.

## 2. DP Mechanism and Privacy-Utility Frontier

For a mini-batch $B$ of trajectories, define the trajectory loss as the sum over transitions.

$$L_i(\theta)=\sum_{t=0}^{T_i-1}\ell(\theta;z_{i,t}),\quad z_{i,t}=(s_{i,t},a_{i,t},r_{i,t},s'_{i,t},d_{i,t}).$$

The per-trajectory gradient is

$$G_i=\nabla_\theta L_i(\theta).$$

Trajectory DP-SGD clips the whole trajectory gradient:

$$\bar{G}_i=G_i\cdot\min\left(1,\frac{C}{\|G_i\|_2}\right).$$

The released noisy batch gradient is

$$\tilde{G}=\frac{1}{|B|}\left(\sum_{i\in B}\bar{G}_i+\mathcal{N}(0,\sigma^2C^2I)\right).$$

The parameter update is

$$\theta_{k+1}=\theta_k-\eta\tilde{G}.$$

For Gaussian noise multiplier $\sigma$, the order-$\alpha$ RDP cost of one full Gaussian release is bounded by

$$\varepsilon_\alpha^{\text{Gauss}}=\frac{\alpha}{2\sigma^2}.$$

With subsampling rate $q=|B|/n$, the prototype auditor uses the approximation

$$\varepsilon_\alpha^{\text{sub}}\approx q^2\frac{\alpha}{2\sigma^2}.$$

RDP composes additively across $K$ steps:

$$\varepsilon_\alpha^{(K)}=\sum_{k=1}^{K}\varepsilon_{\alpha,k}=Kq^2\frac{\alpha}{2\sigma^2}.$$

Conversion to $(\varepsilon,\delta)$-DP uses

$$\varepsilon(\delta)=\min_{\alpha>1}\left[\varepsilon_\alpha^{(K)}+\frac{\log(1/\delta)}{\alpha-1}\right].$$

### CQL Under Gaussian Noise

CQL controls OOD overestimation through a conservative penalty:

$$\mathcal{R}_{\text{CQL}}(\theta)=\mathbb{E}_{s\sim\mathcal{D}}\left[\log\int_{\mathcal{A}}\exp(Q_\theta(s,a))da-Q_\theta(s,a_{\mathcal{D}})\right].$$

DP updates perturb the critic. Write the noisy critic as

$$\hat{Q}(s,a)=Q_\theta(s,a)+\xi(s,a),\quad \xi\sim\mathcal{N}(0,\sigma_Q^2).$$

For $m$ sampled OOD actions, a sub-Gaussian union bound gives

$$\Pr\left[\max_{j\le m}\xi_j>\sigma_Q\sqrt{2\log(m/\beta)}\right]\le\beta.$$

The privacy-aware penalty used by the implementation is a concentration correction:

$$\mathcal{R}_{\text{privacy}}(\theta)=(1+\sigma)\mathbb{E}\left[\max(0,\max_j\hat{Q}(s,a_j^{\text{ood}})-\hat{Q}(s,a_{\mathcal{D}}))^2\right].$$

If the Bellman operator is $\gamma$-contractive,

$$\|\mathcal{T}Q_1-\mathcal{T}Q_2\|_\infty\le\gamma\|Q_1-Q_2\|_\infty,$$

then pessimistic OOD regularization keeps Gaussian critic noise from dominating the target outside the logged support. It preserves a practical privacy-utility frontier: stronger noise increases privacy, while the CQL and concentration penalties reduce unsafe optimistic extrapolation.

## 3. Mathematical Formalization of Three Unlearning Strategies

### Strategy 1: Influence Function Unlearning

Let the empirical trajectory risk be

$$R(\theta)=\frac{1}{n}\sum_{i=1}^{n}L_i(\theta),\quad \hat{\theta}=\arg\min_\theta R(\theta).$$

After removing $\tau_k$, the new risk is

$$R_{-k}(\theta)=\frac{1}{n-1}\sum_{i\neq k}L_i(\theta).$$

The first-order influence approximation is

$$\hat{\theta}_{-k}-\hat{\theta}\approx\frac{1}{n}H_{\hat{\theta}}^{-1}\nabla_\theta L_k(\hat{\theta}).$$

The Hessian is

$$H_{\hat{\theta}}=\nabla_\theta^2R(\hat{\theta}).$$

Because deep RL objectives are non-convex, the stable damped system is

$$\left(H_{\hat{\theta}}+\lambda I\right)v=\nabla_\theta L_k(\hat{\theta}),\quad \lambda>0.$$

LiSSA approximates $v=(H+\lambda I)^{-1}g$ by the recursion

$$v_{t+1}=g+\left(I-\frac{H+\lambda I}{s}\right)v_t.$$

The unlearning correction is

$$\theta'=\theta+\eta_uv.$$

With privatized unlearning noise, the update becomes

$$\theta'=\theta+\eta_u(v+\zeta),\quad \zeta\sim\mathcal{N}(0,\sigma_u^2I).$$

The damping term $\lambda I$ controls Hessian indefiniteness and stabilizes the inverse-Hessian vector product.

### Strategy 2: Certified DP Without Additional Action

Differential Privacy bounds model distinguishability for adjacent trajectory datasets:

$$\Pr[\mathcal{M}(\mathcal{D})\in S]\le e^\varepsilon\Pr[\mathcal{M}(\mathcal{D}\setminus\tau_k)\in S]+\delta.$$

For pure DP, total variation is bounded by

$$d_{\mathcal{TV}}(P,Q)=\sup_S|P(S)-Q(S)|\le e^\varepsilon-1.$$

For approximate DP, the relaxed deletion certificate is

$$d_{\mathcal{TV}}\left(\mathcal{M}(\mathcal{D}),\mathcal{M}(\mathcal{D}\setminus\tau_k)\right)\le e^\varepsilon-1+\delta.$$

This provides certified unlearning without parameter changes when the original DP guarantee is strong enough. Legally and ethically, this certificate must be paired with retention policy, audit logs, and domain-specific risk thresholds; it is a mathematical indistinguishability claim rather than a complete governance program.

### Strategy 3: SISA Sharding

SISA partitions trajectories into disjoint episode shards:

$$\mathcal{D}=\bigsqcup_{j=1}^{K}\mathcal{D}_j,\quad \mathcal{D}_j\cap\mathcal{D}_{j'}=\emptyset\ \text{for}\ j\neq j'.$$

The episode-level shard assignment is

$$s(\tau_i)=i\bmod K,\quad \tau_i\in\mathcal{D}_{s(\tau_i)}.$$

A deletion request changes only the affected shard:

$$\mathcal{D}_{s(\tau_k)}'=\mathcal{D}_{s(\tau_k)}\setminus\{\tau_k\}.$$

An ensemble policy can average shard policies:

$$\pi_{\text{ens}}(a\mid s)=\frac{1}{K}\sum_{j=1}^{K}\pi_j(a\mid s).$$

A distilled student minimizes divergence to the ensemble:

$$\min_\phi\mathbb{E}_{s\sim\mathcal{B}}\left[D\left(\pi_\phi(\cdot\mid s),\pi_{\text{ens}}(\cdot\mid s)\right)\right].$$

If every released shard mechanism is $(\alpha,\varepsilon_{\alpha,j})$-RDP, ensemble release composes as

$$\varepsilon_\alpha^{\text{ensemble}}=\sum_{j=1}^{K}\varepsilon_{\alpha,j}.$$

If distillation uses only released private shard policies, it is post-processing:

$$\varepsilon_\alpha^{\text{distill}}=\varepsilon_\alpha^{\text{ensemble}}.$$

Episode-consistent sharding is therefore both a privacy requirement and an RL validity requirement. Splitting a trajectory across shards would corrupt the protected unit and the Bellman temporal structure.
